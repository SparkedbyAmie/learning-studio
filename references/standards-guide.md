# State Standards Reference Guide

This reference maps grade-level expectations across US states. The skill uses this to align every generated activity to the user's configured state.

---

## How Standards Alignment Works

1. The user configures their state in their family profile.
2. For each activity, identify the target skill and grade level.
3. Look up the corresponding standard code and description below.
4. Cite the standard in the worksheet footer (e.g., "Aligned to IN 4.NS.1").
5. If a state-specific code isn't listed, use the Common Core equivalent and note "CCSS-aligned."

---

## State Standards Frameworks

### States Using Common Core (CCSS) or Close Variants
Most states have adopted CCSS or a framework closely based on it. For these states, use CCSS codes directly:

**Full CCSS adoption:** Connecticut, Delaware, Hawaii, Idaho, Illinois, Iowa, Kentucky, Maine, Maryland, Michigan, Montana, Nevada, New Hampshire, New Jersey, New Mexico, New York, North Dakota, Oregon, Pennsylvania, Rhode Island, South Dakota, Vermont, Washington, West Virginia, Wisconsin, Wyoming, District of Columbia

**Modified CCSS (use state-specific names when possible):**
- California: CA CCSS (identical content, state branding)
- Colorado: Colorado Academic Standards (CAS) — closely mirrors CCSS
- Georgia: Georgia Standards of Excellence (GSE)
- Louisiana: Louisiana Student Standards
- Massachusetts: MA Curriculum Frameworks (extends CCSS)
- Mississippi: MS College- and Career-Readiness Standards
- Missouri: Missouri Learning Standards
- North Carolina: NC Standard Course of Study
- Ohio: Ohio Learning Standards
- Tennessee: Tennessee Academic Standards
- Utah: Utah Core Standards

### States with Independent Frameworks
These states have distinct standards requiring specific code references:

#### Indiana Academic Standards
- Code format: `IN [Grade].[Domain].[Standard]`
- Math domains: NS (Number Sense), C (Computation), AT (Algebraic Thinking), G (Geometry), M (Measurement), DA (Data Analysis)
- ELA domains: RL (Reading Literature), RN (Reading Nonfiction), RF (Reading Foundations), W (Writing), SL (Speaking & Listening), L (Language)
- Example: `IN 4.C.5` = Grade 4, Computation, Standard 5

#### Texas Essential Knowledge and Skills (TEKS)
- Code format: `TX [Grade].[Strand].[Standard].[Expectation]`
- Math strands: 1 (Number/Operations), 2 (Algebraic Reasoning), 3 (Geometry/Measurement), 4 (Data Analysis), 5 (Personal Financial Literacy)
- Example: `TX 4.4.H` = Grade 4, Strand 4, Standard H

#### Virginia Standards of Learning (SOLs)
- Code format: `VA [Subject][Grade].[Standard]`
- Example: `VA MATH4.3` = Math Grade 4, Standard 3

#### Florida B.E.S.T. Standards
- Code format: `FL MA.[Grade].[Domain].[Benchmark]`
- Example: `FL MA.4.NSO.2.1` = Grade 4, Number Sense & Operations, Benchmark 2.1

#### Minnesota Academic Standards
- Code format: `MN [Grade].[Strand].[Standard].[Benchmark]`

#### Arizona Academic Standards
- Uses Arizona-specific coding, closely mirrors CCSS content

#### Nebraska
- Code format: `NE MA [Grade].[Standard].[Indicator]`

#### Oklahoma Academic Standards
- Code format: `OK [Grade].[Domain].[Standard]`

#### South Carolina College- and Career-Ready Standards
- Code format: `SC [Grade].[Domain].[Standard]`

#### Alaska
- Uses Alaska-specific coding aligned to CCSS content

## Grade-Level Skill Expectations — Cross-State Core

These represent the consensus expectations across states. Use these when a state-specific breakdown isn't available, or as a planning framework.

### Pre-K / Early Learning
**Literacy:** Letter recognition (uppercase focus), name writing, rhyming, syllable clapping, print concepts (left-to-right, top-to-bottom), 5–10 sight words, oral vocabulary
**Math:** Counting to 20, number recognition 0–10, shapes (circle, square, triangle, rectangle), color names, sorting by one attribute, simple patterns (AB, ABB)
**Motor:** Pencil grip, tracing lines and shapes, cutting with scissors, coloring within boundaries
**Social-Emotional:** Taking turns, following 2-step directions, identifying basic emotions, classroom routines

### Kindergarten
**Literacy:** All uppercase and lowercase letters, letter-sound correspondence, CVC word decoding, 25–50 sight words, writing first and last name, dictating/writing simple sentences, retelling familiar stories
**Math:** Counting to 100 by 1s and 10s, number writing 0–20, comparing numbers (more/less/equal), addition and subtraction within 5, 2D and 3D shapes, measurement comparison (longer/shorter/heavier/lighter)
**Science:** Living vs. nonliving, weather observation, basic needs of plants and animals
**Social Studies:** Family and community, maps (basic), national symbols, rules and responsibilities

### 1st Grade
**Literacy:** Short and long vowel patterns, consonant blends and digraphs, 100+ sight words, reading level D–J texts, writing 3+ complete sentences, capitalizing and punctuating sentences
**Math:** Addition and subtraction within 20 (fluency within 10), place value (tens and ones), telling time to the hour and half-hour, measuring length, data with tally charts and bar graphs

### 2nd Grade
**Literacy:** Multisyllabic word decoding, prefixes/suffixes, reading level J–M texts, writing paragraphs with topic sentence, text evidence for comprehension questions
**Math:** Addition and subtraction within 100 (fluency within 20), skip counting by 2s/5s/10s, place value to 1000, introduction to multiplication concept (equal groups), money, telling time to 5 minutes

### 3rd Grade
**Literacy:** Reading level M–P texts, distinguishing fiction/nonfiction, main idea and supporting details, text features (headings, captions, glossary), writing multi-paragraph compositions, cursive introduction, vocabulary from context
**Math:** Multiplication and division within 100 (fluency for ×0–10), fractions on a number line, area and perimeter, rounding to nearest 10 and 100, two-step word problems, bar graphs and pictographs

### 4th Grade
**Literacy:** Reading level P–S texts, comparing themes across texts, figurative language, text structure (cause/effect, compare/contrast, sequence), multi-paragraph essays with evidence, grammar (compound sentences, verb tenses, pronoun-antecedent agreement)
**Math:** Multi-digit multiplication (up to 4-digit by 1-digit, 2-digit by 2-digit), long division, equivalent fractions, fraction comparison, decimal notation (tenths/hundredths), angle measurement, multi-step word problems, factors and multiples

### 5th Grade
**Literacy:** Reading level S–V texts, analyzing author's purpose and point of view, integrating information across texts, writing opinion and informational essays with research, grammar (complex sentences, comma rules)
**Math:** Multi-digit multiplication and division fluency, fraction operations (add/subtract with unlike denominators, multiply), decimal operations, volume, coordinate plane, order of operations, numerical patterns

### 6th Grade
**Literacy:** Reading level V–Z texts, analyzing argument and claims, citing textual evidence, writing argumentative essays, vocabulary with Greek/Latin roots
**Math:** Ratios and proportional reasoning, division of fractions, integers and rational numbers, expressions and equations, statistical variability, area/surface area/volume

### 7th Grade
**ELA:** Analyzing text structure and development, tracing arguments and evaluating reasoning, writing with claims and counterclaims, academic vocabulary, citing multiple sources
**Math:** Proportional relationships, operations with rational numbers, expressions and equations (two-step), geometry (scale drawings, angle relationships, area/circumference of circles), probability and statistics (random sampling, comparative inferences)
**Science:** Life science (cells, body systems, ecology), Earth science (weather, climate, natural resources)

### 8th Grade
**ELA:** Analyzing how texts use structure for effect, evaluating arguments for relevance and sufficiency of evidence, research-based writing, narrative techniques, connotation and figurative language
**Math:** Linear equations and systems, functions (defining, comparing, modeling), exponents and scientific notation, Pythagorean theorem, transformations and congruence, scatter plots and association
**Science:** Physical science (forces, motion, energy), Earth science (Earth's place in the universe, Earth's systems, human impacts)

### 9th–10th Grade
**ELA:** Analyzing complex characters and themes, evaluating rhetoric and seminal texts, argument writing with valid reasoning and relevant evidence, research projects (multiple sources), vocabulary acquisition strategies, complex sentence structures
**Math (Algebra I / Geometry):**
- Algebra I: Solving linear/quadratic equations, graphing linear/quadratic functions, systems of equations, exponential growth/decay, arithmetic and geometric sequences, modeling with equations
- Geometry: Congruence and similarity proofs, coordinate geometry, trigonometric ratios, area/volume of 3D figures, circle theorems, transformations
**Science (Biology / Chemistry):**
- Biology: Cell biology, genetics and heredity, evolution and natural selection, ecology and ecosystems, body systems
- Chemistry: Atomic structure, periodic table, chemical bonding, reactions and stoichiometry, states of matter, solutions
**Social Studies:** World History or US History (state-dependent), Government/Civics foundations

### 11th–12th Grade
**ELA:** Analyzing foundational US documents and world literature, synthesizing multiple complex texts, argumentative and research-based writing at college-ready level, evaluating rhetoric and reasoning, discipline-specific vocabulary
**Math (Algebra II / Precalculus / Statistics):**
- Algebra II: Polynomial and rational functions, logarithmic and exponential functions, conic sections, sequences and series, complex numbers
- Precalculus: Trigonometric functions and identities, polar coordinates, parametric equations, limits introduction, vectors
- Statistics: Experimental design, probability distributions, normal distribution, inference (confidence intervals, hypothesis testing), regression
**Science (Physics / AP Sciences):**
- Physics: Kinematics, forces and Newton's laws, energy and momentum, waves, electricity and magnetism
- AP courses: mirror College Board course descriptions for AP Biology, Chemistry, Physics, Environmental Science
**Social Studies:** US History, Economics, Government, AP-level courses

## Standardized Test Alignment

When generating test prep materials, align to these frameworks:

### State Assessments
- **Indiana:** ILEARN (grades 3–8), ISTEP+ legacy format awareness
- **Texas:** STAAR (grades 3–8, EOC for Algebra I, Biology, English I/II, US History)
- **Common Core states:** SBAC or PARCC-successor assessments
- **Other states:** Align to the state's published assessment blueprints

### College-Readiness Tests
- **SAT:** Math (Heart of Algebra, Problem Solving & Data Analysis, Passport to Advanced Math, Additional Topics), Evidence-Based Reading & Writing
- **ACT:** English, Math (pre-algebra through trigonometry), Reading, Science Reasoning
- **PSAT/NMSQT:** Same domains as SAT, scaled for 10th–11th grade

### AP Exams
- Align to the College Board's published Course and Exam Description (CED) for each subject
- Mirror released free-response and multiple-choice question formats

- **Social-Emotional:** SE.1 (Self-Awareness), SE.2 (Self-Management), SE.3 (Social Awareness), SE.4 (Relationship Skills)

### Other State Pre-K Frameworks
Most states have published early learning guidelines. When generating Pre-K content, use the state-specific document name if known; otherwise align to the cross-state core expectations listed above.

## Using This Guide

When generating content:

1. Identify the child's entering grade and completed grade from the profile.
2. For **review/mastery content**: use the completed grade's standards.
3. For **preview/readiness content**: use the entering grade's standards.
4. For **summer bridge packets**: aim for 60% review, 40% preview.
5. For **school-year supplemental**: align to the entering grade's current quarter scope and sequence.
6. Always cite the standard in the footer using the state-specific code format.
